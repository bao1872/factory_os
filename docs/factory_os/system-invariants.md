# Factory OS 系统不变量 v1.0

本文件定义任何管理员、设置页、导入、RPC、Connector 或定制代码都不能绕过的规则。它们不是“默认配置”，而是产品正确性边界。

## 不变量

1. **租户隔离**：业务记录必须归属允许的公司；跨公司读取和写入由 company check、ACL 与 record rule 阻断。
2. **原生状态语义**：`sale.order`、`purchase.order`、`stock.picking`、`mrp.production` 的原生状态只表达各自交易生命周期。Factory OS 的执行、健康度、Gate 和风险使用独立字段，不改写原生语义。
3. **库存单一事实源**：在手、预留、可用、移动和批次数量只来自 Odoo `stock.*`。不得建立可独立修改数量的平行库存表。
4. **真实追溯**：追溯关系只根据真实 `stock.move`、`stock.move.line`、`stock.lot`、MO、消耗与产出计算；任何人工备注都不能成为追溯边。
5. **质量影响库存**：失败或拒收的数量必须进入明确的隔离、报废、退货或其他受控库存处置；“仅记录”不能让不合格品继续表现为可自由使用。
6. **成品质检 Gate**：启用质量模块且成品质检 Gate 开启时，未通过成品检验的货物不能进入 Ready-to-Ship；任何按钮、导入或 RPC 都必须执行同一校验。
7. **健康度语义统一**：全系统只有正常、预警、风险三种健康度语义与固定颜色映射；健康度不是业务阶段，严重质检失败不可被隐藏或映射为正常。
8. **安全底线**：操作员默认不得读取客户报价、供应商价格、成本/毛利、系统设置或超出范围的仓库/班组记录；菜单隐藏不视为安全控制。
9. **Connector 最小披露**：共享字段采用白名单；凭据、密码、token、内部备注、审计细节和明确标记的私有字段永久禁止外发。“共享全部字段”不存在。
10. **强制审计**：配置、权限、Gate、质量结论、库存处置和 Connector 授权的关键变更必须保留 Who/What/When/Before/After；不得由业务配置关闭。
11. **配置依赖一致**：依赖未满足时系统自动阻止或隐藏选项；例如生产必须依赖库存及产品/BOM，成品质检 Gate 必须依赖质量模块。
12. **日期完整性**：客户要求日期与客户确认日期必须存在并经过时区一致的校验；计划完成日期可以隐藏，但不能替代二者。

## 执行层

| 层级 | 必须措施 |
|---|---|
| 数据模型 | required/check/company constraints、受控 selection、只读派生字段 |
| 服务层 | 所有按钮、cron、导入、RPC、Connector 复用同一业务校验方法 |
| 权限层 | `ir.model.access.csv` + `ir.rule` + 字段 groups；禁止以菜单隐藏代替授权 |
| 界面层 | 隐藏无效配置、解释依赖、禁止把 C 类不变量渲染为开关 |
| 审计层 | Chatter/tracking 与专用审计记录覆盖关键变更，敏感值脱敏 |
| 测试层 | 正向流程、越权、跨公司、导入/RPC 绕过、并发和回归测试 |

## Phase 1 退出条件

- 普通用户经菜单、URL、RPC、导出均无法读取越权字段或记录。
- 跨公司创建、读取、更新和关联测试全部被阻止。
- 禁用依赖模块后，不产生残缺状态或孤立配置。
- 失败质检无法通过任何入口绕过库存处置与发货 Gate。
- Connector 测试载荷只包含白名单字段，私有字段为零泄漏。
- 每项配置变更和关键业务变更均能还原操作者、时间、前后值。

任何一项失败都不得通过增加“允许绕过”配置解决；应修正模型、权限、服务或测试。
